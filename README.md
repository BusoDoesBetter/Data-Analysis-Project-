# Exploratory Data Analysis (EDA): Automobile Dataset 🚗📊

> A modular Python data analysis pipeline and statistical report exploring vehicle pricing, fuel efficiency, engine capacity, and manufacturer market share across imported automobiles[cite: 4, 5].

---

## 📋 Project Overview
Developed as a Data Science Capstone Project, this repository demonstrates end-to-end exploratory data analysis (EDA) on the `automobile.txt` dataset[cite: 4, 5, 15]. The project focuses on writing clean, modular, PEP 8-compliant Python code with defensive error handling to sanitize raw vehicle records, uncover statistical relationships, and communicate insights through data visualizations[cite: 4, 15, 16].

---

## 🛠️ Tech Stack & Tools
* **Language:** Python 3.14
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Environment:** Jupyter Notebook / VS Code[cite: 4]
